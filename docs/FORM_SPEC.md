# 智链宝 V2.0 — FORM_SPEC.md

> 版本：v1.0

# 1. 通用校验

## 1.1 服务端为准

所有表单：

```text
前端即时提示
+
服务端 Zod/Schema 最终校验
```

不得只依赖 HTML required。

## 1.2 文本

技术默认上限建议：

```text
人员姓名          80
企业/组织名称     200
业务标题          200
短说明            1000
长说明/进展       5000
备注              2000
```

若未来有正式模板要求再调整。

输入：

- trim首尾空格；
- 保留正文内部换行；
- 不允许脚本/危险HTML；
- 富文本只在明确需要的公告中使用安全白名单。

## 1.3 手机号

账号手机号：

> 中国大陆手机号标准化为纯11位数字。

企业联系人/组织电话：

> 允许合法手机号或办公电话，保存标准化展示值，不强制都作为登录手机号。

## 1.4 附件

单文件 ≤ 50MB。

上传失败不清空表单。

草稿可保留临时附件。

# 2. 登录 / 账号

## 登录

```text
phone           必填
password        必填
```

错误文案不区分“手机号不存在/密码错”。

## 首次改密

```text
new_password
confirm_password
confidentiality_confirm = true
```

校验：

- >=8；
- 两次一致；
- 不等于本人手机号后8位。

# 3. 企业公开需求填报

入口已绑定 `area_id`，企业不能修改。

字段：

```text
企业名称        必填
联系人          必填
联系电话        必填
需求标题        必填
需求描述        必填
信息真实确认    必选
同意镇区联系    必选
附件            可选
```

企业**不填写**：

```text
需求类型
紧急程度
```

提交：

- 行为验证；
- rate limit；
- 重复检测；
- 生成 XS 参考编号；
- 只返回“镇区工作人员将与您联系”；
- 不提供进度查询。


- 不填标题；

# 23. 业务编号

服务端生成，不允许客户端输入。

```text
XS
XQ
BX
QZ
```

格式：

```text
{PREFIX}-{YYYY}-{6位顺序}
```

生成必须事务安全。

不得通过：

```text
count(*) + 1
```

产生并发重复。
